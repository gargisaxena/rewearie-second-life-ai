# Rewearie: Your Style's Next Chapter

Create a responsive fashion-tech web application called "rewearie".

Brand name should always be styled in lowercase:

rewearie ♡

Tagline:

"give your clothes another little life."

PRODUCT CONCEPT:

Rewearie is an AI-assisted circular fashion platform.

Users upload a photo of clothing they no longer wear.

The application helps them decide whether the item should be:

Reworn

Repaired

Upcycled

Resold

Donated

Recycled

The goal is to help clothing have another life rather than immediately becoming waste.

IMPORTANT DESIGN DIRECTION:

The visual style must remain consistent throughout the entire application.

The aesthetic is:

Pinterest-inspired

soft femininity

mature girly

fashion editorial

romantic minimalism

premium sustainable fashion

modern fashion-tech startup

DO NOT make it childish.

COLOR PALETTE:

Primary background cream: #FFF9F7

Soft blush: #F8E4E7

Pastel pink: #F3CDD5

Dusty rose accent: #C98F9E

Deep rose: #9E6373

Warm beige: #EDE2DA

Soft sage accent: #CBD5C0

Charcoal text: #302A2C

DESIGN RULES:

- Cream should be the dominant background.

- Pink should be used intentionally, not everywhere.

- Use dusty rose for important actions.

- Use sage only as a subtle sustainability accent.

- Lots of whitespace.

- Elegant editorial layout.

- Large sophisticated serif headings.

- Clean modern sans-serif body text.

- Soft subtle shadows.

- Rounded corners but not excessively rounded.

- Avoid bubble-like UI.

- Avoid bright colors.

- Avoid neon.

- Avoid generic blue SaaS UI.

- Avoid excessive gradients.

- Avoid childish illustrations.

- Avoid clutter.

- Use subtle, elegant animations.

Create these main pages:

1. Home

2. Analyze

3. Results

4. My Pieces

5. Impact

Navigation should include:

rewearie ♡

Analyze

My Pieces

Impact

Add a prominent button:

"analyze a piece ♡"

Make desktop and mobile layouts beautiful and responsive.
